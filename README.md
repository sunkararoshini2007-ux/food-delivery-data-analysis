# Food Delivery Data Analysis 

## Project Overview

This project analyzes food delivery data to find useful patterns and trends in orders, restaurants, food items, locations, order amounts, and delivery delays.

A machine learning classification model is also used to classify the **delivery delay status**.

## Domain

**Data Science & Machine Learning**

## Sub-Domain

**Machine Learning**

## Problem Type

**Classification**

## Application Area

**Food Delivery / Restaurant Analytics**

## Project Goal

To analyze food delivery data and classify delivery delay status using machine learning.

## Objectives

* Analyze food delivery data.
* Find order and delivery patterns.
* Analyze restaurants and food items.
* Study delivery delays.
* Create charts and graphs.
* Classify delivery delays using machine learning.

## Dataset

The project uses a Food Delivery dataset containing information about orders, customers, restaurants, locations, order values, delivery distance, delivery delay, and customer-related information.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Data Analysis

The project performs analysis on:

* Most ordered food items
* Popular restaurants
* Orders by location
* Order amount and revenue
* Delivery time and delay
* Customer-related patterns

## Machine Learning

### Algorithm

**Random Forest Classifier**

### Target

**Delivery Delay Status**

* `0` – Not Delayed
* `1` – Delayed

### Features

* Delivery distance
* Order value
* Age
* Order history
* Food freshness
* Packaging quality

## Model Evaluation

The model is evaluated using **accuracy** to measure how correctly it classifies delivery delay status.
